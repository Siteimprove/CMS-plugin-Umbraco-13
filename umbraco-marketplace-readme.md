# Siteimprove Content Assistant for Umbraco 17

Integrates Siteimprove Content Assistant with Umbraco CMS 17 on .NET 10, for
Umbraco Cloud and self-hosted applications.

Features include published-page insights, preview prepublish checks and
highlighting, multilingual URL resolution, and optional public-domain mapping.

Version 1.0.0-beta.2 is for customer testing. Stable release requires acceptance on
Cloud and self-hosted Umbraco 17. The package is not yet published to NuGet.org.

See [README.md](README.md) for installation, configuration, connectivity
requirements, and preview-provider limitations.
