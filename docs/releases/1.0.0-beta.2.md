# Siteimprove for Umbraco 17 — 1.0.0-beta.2

This beta brings Siteimprove Content Assistant to **Umbraco 17.7.1+ (17.x)** on
**.NET 10**. The same package is intended for Umbraco Cloud and self-hosted sites.
Use it in a test environment and share feedback before a stable release.

## Download and install

Download `Siteimprove.Umbraco17.Plugin.1.0.0-beta.2.customer.zip` from this
release's assets. It includes the NuGet package, installation and usage guides,
beta notes, build provenance, and SHA-256 checksums. A standalone `.nupkg` is
also available for an internal NuGet feed.

Follow the [installation guide](https://github.com/Siteimprove/CMS-plugin-Umbraco-13/blob/master/docs/INSTALLATION.md)
for local installation, Cloud deployment, on-premises deployment, and upgrading
from the Umbraco 13 plugin. The package is not published to NuGet.org; configure
a local or internal feed as described in the guide.

After configuring the feed, install the package in your Umbraco web project:

```sh
dotnet add src/YourSite/YourSite.csproj package Siteimprove.Umbraco17.Plugin --version 1.0.0-beta.2
```

Replace the project path with your own. Configure the plugin under
**Settings → Siteimprove**. See the
[usage guide](https://github.com/Siteimprove/CMS-plugin-Umbraco-13/blob/master/docs/USAGE.md)
for public-domain settings and editor workflows. Installing this package does
not upgrade the CMS; remove the v13 plugin and its old browser assets first.

## Included in this beta

- Native Umbraco 17 backoffice integration, with configuration in Settings.
- Published-page context that follows document selection, saving, and publishing.
- Full-page preview checks and highlighting for server-rendered Umbraco previews.
- Optional public-domain mapping, including environment configuration overrides
  and retention of the v13 saved setting.
- Beta.2 fixes for document permissions, delayed initialization, and context
  teardown, plus consistent package versions across the build and test host.

## Validation and remaining checks

The [verified build](https://github.com/Siteimprove/CMS-plugin-Umbraco-13/actions/runs/38471887229)
passed **19 JavaScript tests, 26 backend tests**, NuGet installation/publish
checks, and a Playwright flow against real Umbraco 17.7.1. Both the plugin flow
and the plugin-disabled control reported zero browser errors.

The browser tests stub Siteimprove's overlay. Live Siteimprove account checks,
actual Cloud/Windows deployments, multilingual/multisite routing, and custom
CSP/proxy acceptance remain pending. External/headless previews need their own
integration. This is a **prerelease for customer testing**, with production
acceptance still open. See
[validation details](https://github.com/Siteimprove/CMS-plugin-Umbraco-13/blob/master/docs/VALIDATION.md).

The binary assets come unchanged from the verified build of source commit
`49d70214c8697936724f6717f5ad07a03aacf0ea`. Use the customer ZIP's `release.json`
and `SHA256SUMS` to check provenance and integrity. The standalone installation
and usage guide attachments include the latest documentation.
