# Siteimprove Content Assistant 1.0.0-beta.8

This beta includes the preview fixes from beta.7 and makes upgrades invalidate cached plugin scripts.

- Prepublish scans analyze the rendered page without including the assistant's own tooltip or panel.
- “View on platform” opens a new tab from native Umbraco previews.
- Preview scripts and imported helper modules use versioned URLs, preventing older cached scripts from breaking an upgraded editor.

The browser suite covers published and unpublished previews, clean scan documents, highlighting, platform links, navigation, and stale unversioned assets across Chromium, Firefox, and WebKit. Customer acceptance remains a separate release gate; this is a prerelease package.
