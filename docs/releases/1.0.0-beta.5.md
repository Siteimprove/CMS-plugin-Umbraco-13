# Siteimprove Content Assistant 1.0.0-beta.5

- Hide the launcher and open panel when the backoffice session expires; restore the current document after sign-in.
- Ignore queued document and authorization events from replaced or destroyed contexts.
- Hide the assistant in template and document-type workspace modals; restore it when returning to content.
- Generate isolated draft sessions on HTTP backoffices where `crypto.randomUUID` is unavailable.
- Require patched .NET cryptography packages (Pkcs and Xml 10.0.13).
- Expand regression coverage to Chromium, Firefox and WebKit, isolated CMS fixtures, saved draft field text, session recovery and non-content modals.

This remains a customer beta. The current test site's published-page results await Siteimprove's site review. The full CMS still inherits ImageSharp 3.1.12 audit warnings. Cloud and Windows/IIS acceptance remain separate.
