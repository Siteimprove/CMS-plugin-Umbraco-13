# Siteimprove for Umbraco 17 — 1.0.0-beta.7

Native Umbraco previews now host Content Assistant in the outer preview window.
Prepublish checks still receive the rendered page document, and highlighting
still targets that page. The page's sandbox permissions remain unchanged.

This fixes two preview issues:

- The assistant launcher and its tooltip could be included in prepublish checks,
  producing policy matches against the assistant's own text.
- “View on platform” links could not open a new tab inside Umbraco's sandboxed
  page iframe. The assistant now opens these links from the outer preview window.

Internal preview navigation reuses the existing assistant and registers the new
page document. Unloaded pages release their callbacks without clearing a newer
preview's context. The beta.6 nested-editor restoration fixes are included.

Browser regressions check that the scanned document contains no assistant UI,
highlighting uses the rendered page, the native sandbox is unchanged, and a
platform link opens a new tab. The three-engine suite uses a stub service;
real-service acceptance is recorded separately after deployment.

Install using the [installation guide](../INSTALLATION.md), and review the
[usage guide](../USAGE.md) and [remaining acceptance checks](../VALIDATION.md).
This is a customer beta, not a stable Marketplace release.
