# Siteimprove for Umbraco 17 — 1.0.0-beta.4

Unpublished drafts and cultures no longer share cached prepublish results. Each
rendered preview receives a fresh, opaque result session. Draft editor contexts
also receive isolated sessions before their URL lookup completes. Published pages
continue to use their public URL for result history.

URL-less previews explicitly clear live-page context before registering their
prepublish callback. Opening or reloading an unpublished preview starts without
previous results; run a content check to analyze that rendered draft. Results
remain available while that preview is open, including Recheck draft and
highlighting. The result session is unrelated to backoffice authentication.

Regression coverage checks session uniqueness across drafts, cultures and repeated
renders, preservation during overlay initialization, late-response protection,
returning to published URL-based results, and full-page callbacks. The real-CMS
browser suite seeds a shared stale result and checks that separate drafts and a
reopened preview cannot display it.

The package remains a customer beta for Umbraco 17.7.1+ (17.x) on .NET 10. Actual
Siteimprove analysis and deployment verification are recorded separately from the
stubbed automated browser suite. Existing hosting acceptance and dependency audit
items remain open.
