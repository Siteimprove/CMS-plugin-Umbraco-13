# Siteimprove Content Assistant 1.0.0

The first general availability release for **Umbraco CMS 17.7.1+ within 17.x**
on **.NET 10**. Install `Siteimprove.Umbraco17.Plugin` version `1.0.0` from NuGet.org
after publication. A valid Siteimprove account is required.

## Features and fixes

- Published-page insights follow the selected document and culture, including
  save/publish changes and restoration after nested document editors close.
- Full-page prepublish checks analyze saved, rendered drafts, including pages
  without a published URL. Highlighting targets the rendered page.
- Native previews host the assistant outside the scanned page, preventing its
  tooltip from producing false policy matches and enabling platform links to
  open a separate tab while keeping Umbraco's iframe sandbox intact.
- Versioned browser assets prevent old cached plugin modules from breaking upgrades.
- Configuration lives under **Settings → Siteimprove**, with an optional public
  domain mapping and per-environment configuration overrides. The v13 database
  setting is retained.
- Management API access requires backoffice authentication; settings require
  administrator access and document URLs require browse permission.

The runtime behavior matches the accepted beta.8 build. This release promotes
the package to 1.0.0, updates cache versions and adds stable release packaging
and documentation. It does not upgrade the site's CMS.

## Installation and compatibility

See [installation](../INSTALLATION.md), [usage](../USAGE.md) and
[package verification](../DISTRIBUTION.md). Remove the v13 plugin and its legacy
assets when separately upgrading a CMS to v17. Umbraco 13 retains its own package
and source branch. Umbraco 14–16 and 18 are outside this package's supported range.

## Validation and known limits

The project owner confirmed successful functional testing on 22 October 2026.
The accepted beta.8 completed 57 JavaScript, 38 backend, eight bundle and 18
browser tests across Chromium, Firefox and WebKit. Release packaging adds stable
bundle regressions; use the final artifact's `release.json` to identify its CI run.

Real-service testing on self-hosted Umbraco 17.7.1 confirmed a completed draft
check with zero false policy issues and a platform link opening in a new Chrome
tab. The project owner also confirmed that live view works and the page report
is accessible when the site has been crawled. Automated browser tests stub the
vendor service.

Cloud, Windows/IIS, upgraded v13 databases and custom hosting configurations have
not been independently certified. Headless/external previews need their own
integration. Inherited CMS ImageSharp/MessagePack advisories and native backoffice
lifecycle errors remain documented in [validation](../VALIDATION.md). No CMS
security or lifecycle fix is claimed by this release.
