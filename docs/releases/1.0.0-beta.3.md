# Siteimprove for Umbraco 17 beta 3

Beta.3 fixes preview URL resolution and scopes the launcher to content editing
and rendered preview on Umbraco 17.7.1 and .NET 10.

- Renamed saved drafts retain the published URL for live insights.
- Never-published content has no live URL and still supports prepublish checks.
- Published URL resolution restores request preview state, including after a provider error.
- Leaving a document hides the launcher and an open panel; drafts retain access.
- Regression coverage includes preview URLs, navigation, visibility, ownership
  races, unpublished cultures and URL-provider failure recovery.

Install `Siteimprove.Umbraco17.Plugin` version `1.0.0-beta.3` from the generated
local or internal NuGet feed, rebuild, deploy and reload the backoffice.
